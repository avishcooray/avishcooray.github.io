Digital Twin for Smoke Characterization
ML Pipeline & Data Engineering Lead
Spring 2026

Built a digital twin to predict smoke particle profiles from combustion experiments, reducing the need for physical burns. Fused multi-instrument sensor data with a Gaussian process surrogate model to estimate particle concentrations across fuel types and exposure conditions — targeting PPE design and respiratory safety applications.

Data Pipeline
  • Built a 6-module Python pipeline ingesting two particle sensor instruments plus cone calorimeter time series across 100+ experiments — handling instrument-specific quirks including dilution corrections, transposed file layouts, and 60-second time-bin alignment
  • Applied metadata filtering to select only experiments passing all instrument validity checks; enforced min-duration guards and pre-ignition row removal
  • 23 pytest unit tests across all modules; processed data stored in Parquet on HPC cluster
Surrogate Model
  • Trained a Gaussian process regressor with composite ARD kernel (Matérn × RBF + WhiteKernel) to predict total particle number concentration across burn phases
  • Used experiment-grouped train/test split to prevent data leakage; one-hot encoded fuel material categories alongside continuous combustion features
  • Improved model R² from 0.026 to 0.759 across held-out experiments through kernel design, feature engineering, and proper group-aware splitting
